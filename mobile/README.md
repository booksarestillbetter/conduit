# conduit_mobile

The official Flutter mobile client for [Conduit](../README.md) — a unified, multi-node media
fetching commander and lifecycle automation daemon. Pairs with a running Conduit server via
QR-code device linking and gives you live torrent telemetry, pipeline browsing, and node
management from your phone.

## Getting Started

```bash
flutter pub get
flutter run
```

Requires a running Conduit server to connect to — see the [main README](../README.md) for
server setup.
